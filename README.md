# JJ픽

짧은 영상으로 확인하고, 한 페이지에서 고르는 주방·가전·리빙 살림 꿀템 추천 서비스

- 배포 주소: https://jj2210-j.github.io/jjpick-intro/

## 2주차: 서비스 소개 페이지 HTML 구조 확장

### 바꾼 구조

| 1주차 | 2주차 |
|---|---|
| `h1` 제목과 인사 문단 하나 | `header` 안에 서비스 이름, 한 줄 소개, 페이지 내부 이동 메뉴(`nav`) |
| 본문 구분 없음 | `main` 안에 서비스 소개, 주요 기능, 이용 방법, 추천 요청 `section` 4개 |
| 없음 | `footer`에 맨 위로 이동 링크와 저작권 표시 |

### 처음 계획과 수정한 점

- **이미지 위치:** 처음에는 서비스 소개 맨 위에 그림을 두었지만, 문제 설명을 먼저 읽고 그림으로 이해를 돕도록 소개 문단 아래로 옮겼습니다.
- **기능 이름:** 처음에는 "짧은 영상 추천"처럼 서비스 입장에서 이름을 지었지만, 사용자가 무엇을 할 수 있는지 바로 알 수 있도록 "짧은 영상으로 확인하기"처럼 사용자 행동으로 바꿨습니다.
- **입력 영역:** 처음에는 카테고리 선택과 제품 입력 두 가지를 두었지만, 핵심 행동인 추천 요청에 집중하도록 제품 입력 하나와 버튼 하나로 줄였습니다.

### 정보 순서를 정한 이유

처음 방문한 사용자가 "무슨 서비스인지 → 무엇을 할 수 있는지 → 어떻게 쓰는지"를 차례로 이해한 뒤 추천을 요청하도록, 입력 영역을 페이지 마지막에 두었습니다. 내용이 길어도 원하는 부분으로 바로 갈 수 있게 `header`에 이동 메뉴를 넣었습니다.
